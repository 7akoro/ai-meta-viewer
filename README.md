# NovelAI Metadata Viewer - Releases

本地批量查看 AI 图片元数据的桌面工具。  
A desktop app for browsing AI image metadata in bulk.

---

## 中文说明

### 这是什么
`NovelAI Metadata Viewer` 用来快速整理和查看本地 AI 图片信息，适合素材管理、提示词复盘和参数对比。

### 功能亮点
- 批量浏览本地图片目录（支持拖拽导入）
- 一键查看图片内嵌 Prompt 与参数
- 支持多种常见来源元数据：
  - NovelAI
  - AUTOMATIC1111 / Forge
  - ComfyUI
- 支持标签分类显示与彩色标签
- 支持标签右键菜单（复制、搜索、查看分类等）
- 支持全局搜索与当前目录搜索
- 支持 `AND` 组合检索与 `*` 通配符
- 支持文件夹树管理（分类、排序、重命名、移动）
- 支持自动更新检查与手动下载更新

### 常用操作
- 左键图片卡片：打开元数据查看
- 右键图片卡片：打开大图预览
- `← / →`：切换图片或翻页
- `Esc`：关闭查看器/预览
- 滚轮：在预览中切换图片

### 适用场景
- 整理大量 AI 生成图
- 回看历史 Prompt 与生成参数
- 快速筛选指定角色、风格或关键词
- 比较不同模型/工作流的出图参数

## English

### What it is
`NovelAI Metadata Viewer` helps you organize and inspect local AI images, especially for prompt review and parameter comparison.

### Key Features
- Bulk image browsing with drag-and-drop import
- Quick metadata view (prompt + generation params)
- Supports major embedded metadata sources:
  - NovelAI
  - AUTOMATIC1111 / Forge
  - ComfyUI
- Classified and colorized tag display
- Tag context menu (copy, search, category info, etc.)
- Global or current-folder search scope
- Advanced query support with `AND` and `*` wildcard
- Folder tree management (group, reorder, rename, move)
- Auto update check with manual download fallback

### Quick Controls
- Left-click card: open metadata viewer
- Right-click card: open lightbox preview
- `← / →`: navigate images/pages
- `Esc`: close viewer/lightbox
- Mouse wheel: navigate images in lightbox

### Great For
- Managing large AI image collections
- Reviewing old prompts and generation settings
- Fast filtering by character/style/keyword
- Comparing outputs across models and workflows
